### <samp>04 / RULES I BUILD BY</samp>

~~~javascript
if (repetitive) automate();
if (complex)    clarify();
if (valuable)   ship();

always.iterate();
~~~

| Rule | Translation |
|:--|:--|
| **Outcome over ceremony** | Start from the real problem and deliver something useful. |
| **Automation over repetition** | Every repeated task is an unbuilt system. |
| **Clarity over complexity** | Good solutions are understandable, maintainable, and focused. |
| **Iteration over perfection** | Build, test, learn, refine — momentum compounds. |
